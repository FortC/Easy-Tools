# Easy-Tools 产品与技术方案

> 版本：v0.1 ｜ 日期：2026-10-19 ｜ 状态：方案已定稿，开发未启动

## 0. 范围声明

- 隐私模式（含：对录屏/截屏隐身、绕过切屏检测、绕过粘贴检测、进程/窗口隐藏等）。
- 文本输入的"粘贴/手打"两种模式作为**通用输入能力**实现（Quicker 标配），不针对任何考试场景做规避设计。
- 其余全部需求（双操作区、快捷打开与文本输入、事件链、Office 框选处理、配置中心、中键触发）均纳入本方案。

## 1. 产品定位

Windows 桌面效率工具（类 Quicker 指尖工具箱）。核心体验：**鼠标中键在任意位置呼出"动作面板"**，按当前上下文展示公共动作与针对当前软件的专属动作，一键执行。

设计原则：

- 轻量驻留：常驻托盘，内存占用低
- 本地化：全部能力本地运行，不依赖云服务
- 可配置：动作、规则、触发方式均可在配置中心自定义

## 2. 功能设计

### 2.1 双操作区

**公共操作区**：全局可用的动作组，任何应用、任何界面都显示。

**特定操作区**：随上下文动态加载。上下文识别分两级：

| 识别层 | 手段 | 识别内容 | 用途 |
|---|---|---|---|
| L1 应用识别 | 前台窗口进程名 + 窗口标题正则 | 当前是什么软件（WINWORD.EXE / EXCEL.EXE / chrome.exe…） | 加载该软件专属动作组 |
| L2 内容识别 | 轻量本地 OCR（RapidOCR）识别窗口客户区 | 界面上是什么内容/状态（关键词匹配） | 更细粒度动作匹配，如页面关键词、文档区域文字 |

两级组合的原因：进程名识别"是哪个软件"准确且零成本；OCR 识别"界面里是什么内容"，两者正交互补。OCR 走后台线程 + 防抖（窗口切换后约 300ms）+ 结果缓存，不拖慢面板弹出。

匹配规则可配置：`条件（进程名 / 标题正则 / OCR 关键词）→ 显示动作组`。

### 2.2 全局中键触发 + Quicker 式网格面板

- 低级鼠标钩子（SetWindowsHookEx WH_MOUSE_LL，经 pynput/ctypes 封装）监听全局中键。
- 触发判定：**短按（按下+释放且未拖动）→ 呼出面板；按住拖动 → 保持原生滚动**，不破坏浏览器/编辑器的中键滚动习惯。
- 面板：网格布局（图标 + 名称 + 顶部搜索框 + 分组标签），在光标位置弹出，Esc 或点击外部关闭；搜索即时过滤。
- 展示逻辑：公共操作区 + 当前上下文匹配到的特定操作区动作组。

### 2.3 公共操作区动作

**快捷打开类**：应用程序、文件、文件夹、URL、命令行（支持参数、工作目录）。

**文本输入动作**（核心）：

- 目标：把配置好的文本输入到当前光标/焦点位置。
- **粘贴模式**：备份剪贴板 → 写入目标文本 → 模拟 Ctrl+V → 延迟恢复原剪贴板（兼容性最好，Office/浏览器/Java 应用均可用）。
- **手打模式**：SendInput 逐字符键入，可配置基础速度 + 随机间隔抖动，接近真人输入节奏；自动确保目标窗口为前台焦点。
- 动作级可指定模式，也有全局默认。

**文本片段库**：常用语管理（分组、排序、占位变量 `{date}`、`{time}`、`{clipboard}`），片段可绑定为面板按钮。

### 2.4 特定操作区内置规则

- Word/WPS 文字：段落整理、样式/格式快捷操作、表格转换
- Excel/WPS 表格：框选数据快捷处理（与 2.6 剪贴板管线联动）
- 浏览器：常用站点、页面文本抓取（OCR 辅助）
- 规则可在配置中心增删改，按 2.1 两级条件匹配。

### 2.5 事件链 —— 可行性结论：✅ 可行

事件链 = **触发器 → 条件 → 动作序列** 的 JSON 流水线，参考 Quicker"组合动作"：

```json
{
  "name": "整理框选表格",
  "trigger": {"type": "manual"},
  "steps": [
    {"type": "action", "id": "clipboard.copy"},
    {"type": "action", "id": "text.trim_blank_lines", "input": "{clipboard}"},
    {"type": "condition", "expr": "has_table", "then": []},
    {"type": "action", "id": "table.transpose"},
    {"type": "action", "id": "input.paste", "input": "{step2.output}"}
  ]
}
```

- **触发器**：面板手动、热键、窗口切换、剪贴板变化、定时
- **步骤类型**：动作、条件分支、等待、循环、变量赋值
- **变量系统**：`{clipboard}`、`{selection}`、`{ocr_text}`、`{stepN.output}` 在步骤间传递数据
- **编辑器**：配置中心内列表式步骤编辑（增删、排序、参数编辑、试运行）
- 与 2.6 的处理器天然打通：每个剪贴板处理器就是可复用的链步骤

### 2.6 Office/框选数据快捷处理

流程：**框选数据 → 复制（Ctrl+C）→ 中键面板选处理器 → 结果写回剪贴板并自动粘贴**（也可只写回剪贴板）。

内置处理器（均可作为事件链步骤复用）：

- 文本清理：去首尾空白、去空行、合并多空格、去不可见字符
- 表格处理：表格转置、行列拆分合并、CSV/TSV ↔ 表格、Markdown 表格互转
- 数字/格式：千分位、小数位统一、大小写转换、日期格式化
- 数据整理：去重、排序、查找替换、编号填充

### 2.7 配置中心

- 动作库管理：增删改、分组、图标、排序、绑定片段
- 特定操作区规则管理：两级匹配条件 → 动作组
- 触发设置：中键开关、附加热键
- 面板样式：网格列数、尺寸、主题、搜索框
- OCR 设置：开关、语言、防抖时长、识别区域
- 文本输入默认模式与速度
- 配置导入/导出（JSON 单文件，便于备份迁移）
- **保存即生效**（热更新，无需重启）

## 3. 技术选型

| 项 | 选择 | 说明 |
|---|---|---|
| 语言/UI | Python 3.11 + PySide6 | 开发快，UI 能力完整 |
| 全局鼠标钩子 | pynput / ctypes（WH_MOUSE_LL） | 中键全局捕获 |
| 窗口识别 | pywin32 | 前台进程名、窗口标题 |
| OCR | rapidocr_onnxruntime | 本地轻量中文 OCR，约 15MB 模型，CPU 可跑 |
| 文本注入 | win32 SendInput + 剪贴板 | 粘贴/手打两模式 |
| 配置 | JSON 文件 | 可读、可导出 |
| 打包 | PyInstaller | 单目录包，托盘驻留 |

架构分层：

```
easy_tools/
├── main.py              # 入口：托盘、初始化
├── core/
│   ├── hooks.py         # 全局鼠标/热键钩子（中键触发）
│   ├── context.py       # 上下文识别（进程/标题 + OCR 融合）
│   ├── ocr.py           # OCR 服务（后台线程、防抖、缓存）
│   ├── chain.py         # 事件链引擎（JSON 流水线执行）
│   └── actions/         # 动作注册表
│       ├── base.py      # 动作基类 + 注册机制
│       ├── openers.py   # 打开应用/文件/URL/命令
│       ├── text_input.py# 文本输入（粘贴/手打）
│       ├── clipboard.py # 剪贴板处理器（Office 快捷处理）
│       └── system.py    # 其他系统动作
├── ui/
│   ├── panel.py         # 中键呼出的网格面板
│   ├── settings.py      # 配置中心
│   └── chain_editor.py  # 事件链编辑器
├── config/
│   ├── schema.py        # 配置结构定义
│   └── defaults.json    # 默认动作/规则
└── data/
    └── config.json      # 用户配置（运行时生成）
```

## 4. 关键设计决策

1. **中键冲突**：短按弹面板、拖动保持滚动，两类行为互斥判定，不影响原生中键滚动。
2. **OCR 性能**：后台线程 + 防抖 + 缓存；面板弹出不等待 OCR（先按 L1 规则展示，L2 结果到达后动态补充分组）。
3. **文本输入可靠性**：粘贴模式做剪贴板延迟恢复；手打模式先确保目标窗口前台焦点。
4. **配置热更新**：保存即生效，钩子与规则动态重载。
5. **全部本地离线**运行，不上传任何数据。

## 6. 验收标准（开发完成后）

1. 任意应用中按中键弹出面板，搜索/分组可用。
2. 文本输入两模式在记事本、浏览器、Word 中正确落到光标位置。
3. 切换到 Word/Excel 后，面板自动出现对应动作组。
4. 框选 Excel 数据 → 一键"去空行 + 转置"→ 自动回填。
5. 事件链示例（复制 → 清理 → 粘贴）一键跑通。
6. 配置中心改动保存后立即生效。
