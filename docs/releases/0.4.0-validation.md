# Easy-Tools 0.4.0 发布验证记录

日期：2026-10-23。基线：`c34c503776fe89fd616fee32606b94d101e00e96`（0.3.0）。

## 本次交付

- 办公工具页及原文/结果预览，新增 Word 文字整理、Excel 表格处理能力；14 个可选择创建的工作流模板，自动关联面板按钮。
- 工作流步骤树、同页条件/循环、参数表单、草稿编辑、样本试运行、停止及逐步运行记录。
- 显式授权的 Office 快捷键宏及 Python 节点；内容修改需重新授权，导入撤销授权。宏不是 VBA/COM 文档宏；Python 以当前账户权限执行，不是安全沙箱。
- 一次、每日和间隔提醒，通过应用自有受保护窗口显示；应用退出后不运行，不能唤醒休眠/关机设备。
- 新增窗口继承隐私模式；捕获排除设置失败时遮住内容。默认减少阴影，模型空闲释放，后台任务有界、可取消，受控子进程树随归属清理。

Word/Excel 工具处理复制出的文本或 TSV，保留原始文件；本版不提供批量修改 `.docx/.xlsx` 文件、VBA 录制或全局键鼠录制。

## 可复现命令

Windows x64、Python 3.12。构建使用 `requirements-build.txt` 中已验证的依赖，模型及 llama 前置文件见开发规范。

```powershell
.venv\Scripts\python.exe -X utf8 -X faulthandler -m pytest -q
.venv\Scripts\python.exe -X utf8 build.py --tag 0.4.0-final --no-smoke
.venv\Scripts\python.exe -X utf8 build_installer.py --tag 0.4.0-final

# 在隔离账户或单独设置 APPDATA 的进程中运行；只使用合成数据。
.\dist-0.4.0-final\Easy-Tools\Easy-Tools.exe --selftest-upgrade --native --output <诊断目录>
.\dist-0.4.0-final\Easy-Tools\Easy-Tools.exe --selftest-capture --report <诊断目录>\capture.json
```

本地详细诊断、截图及运行报告保存在忽略提交的 `evidence/release-0.4.0/`，不包含用户办公文档。诊断截图用于人工检查布局；真实捕获排除另由上述 GDI 对照验证。
