# Easy-Tools 0.4.2 发布验证记录

日期：2026-10-23。发布基线：当前分支包含动作面板工作区避让修复及 Word `.docx` 文档知识库检索问答。发布标签尚待推送，GitHub Release 尚未创建。

## 变更

- 动作面板使用触发点所在显示器的可用工作区（排除任务栏），在屏幕上下左右边缘按可用空间翻转；动作区高度根据触发显示器工作区计算。
- 增加底部任务栏避让与左上角定位回归用例。
- 知识库新增 Word `.docx`：本机解析正文标题、段落与表格，按片段检索并由当前模型回答，展示文档出处；Excel 仍使用答案列映射和原答案直出，`.doc` 提示另存为 `.docx`。
- 文档片段按不可信资料传给模型；启用 Word 知识库而未检索到足够相关的片段时，拒绝让模型凭空回答。

- 知识库与配置页专项：13 passed，覆盖 `.docx` 正文/表格抽取、出处、检索结果及文档证据进入模型的路由。

## 最终程序原生验证

- 极速版和完整版最终目录 EXE 的 `--selftest-upgrade --native` 均通过；9 类应用窗口均确认 `GetWindowDisplayAffinity=0x11`。合成工作流完成，UI 心跳最大间隔 32ms。
- 极速版与完整版最终 EXE 的 `--selftest-capture` 均通过真实 GDI 桌面捕获、RapidOCR 合成题目识别、答案定位、取消操作和隐私启用/关闭检查；`native_desktop_capture_ocr=true`、`native_affinity_verified=true`、`qt_errors=[]`。
- 极速版目录载荷未发现 `.gguf`；完整版包含一个 `SmolLM2-360M-Instruct-Q4_K_M.gguf`，270,590,880 字节。
