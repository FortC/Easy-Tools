# Easy-Tools
Easy-Tools is a Windows productivity tool with a middle-click action panel at your cursor. Access app-specific shortcuts, process text, organize tables, and automate workflows without leaving your current window. Easy-Tools 是一款 Windows 效率工具，鼠标中键即可在光标处唤出动作面板，支持快捷操作、文本处理、表格整理与流程自动化，并根据当前应用展示专属功能
