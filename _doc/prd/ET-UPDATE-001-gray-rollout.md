# ET-UPDATE-001：Easy-Tools 灰度更新

- 需求编号：ET-UPDATE-001
- 项目：Easy-Tools
- 日期：2026-10-20
- 更新平台需求：DC-001 多软件增量发布平台（`E:\clb-pjs\downloadcenter\_doc\prd\DC-001-update-service.md`）

## 需求

为 Windows 桌面程序 Easy-Tools 增加接入自托管增量更新服务的能力。新版本先按稳定安装实例的灰度比例逐步开放，只有被选中的实例能看到和下载该版本；发布者可以逐级扩大比例。更新检查与下载不阻塞界面，校验完整的文件由独立更新助手在主程序退出后安装，配置和用户数据不被清理。

## 验收点

- [ ] ET-UPDATE-001-AC1：同一安装保持稳定的匿名灰度分组 ID；按应用与 ID 的 SHA-256 确定性分桶，使提高版本灰度比例时已有灰度用户保留在组内。不得上传机器名、Windows 账户或个人信息。
- [ ] ET-UPDATE-001-AC2：版本元数据带 0–100 整数灰度比例；0% 无人收到，100% 全员收到；未入选用户不显示该候选版本，历史稳定包不受影响。
- [ ] ET-UPDATE-001-AC3：Easy-Tools 设置页能查看当前/候选版本、检查更新和确认安装；检查及下载通过后台任务运行并显示进度或结果。
- [ ] ET-UPDATE-001-AC4：使用 HTTPS 验证更新服务证书；下载后校验清单与 SHA-256；服务器不可用、候选未开放或内容损坏时现有程序可继续使用。
- [ ] ET-UPDATE-001-AC5：更新程序在 Easy-Tools 退出后工作，安全切换受管文件、校验安装结果，并在失败时恢复旧版；保留 APPDATA 用户配置、日志、数据以及安装目录中未受管文件。
- [ ] ET-UPDATE-001-AC6：首次安装程序携带必要的更新入口、客户端和 HTTPS 信任证书；已有用户升级到接入版本后可更新，不要求手工替换源码文件。
- [ ] ET-UPDATE-001-AC7：更新服务允许发布者设置灰度比例并重复发布新的唯一版本，比例升级流程在接入指南中有说明。
- [ ] ET-UPDATE-001-AC8：完成针对灰度桶边界、增量校验、失败恢复和现有安装器流程的回归验证，构建版本包与安装器并核对载荷。
- [ ] ET-UPDATE-001-AC9：先连接公司更新服务 `192.168.99.206:9443`；公司服务网络不可达或返回服务端错误时，自动回退到腾讯云 HTTPS 更新域名，严格验证两端 TLS 且不上传本机灰度 ID。

## 方案约束

更新服务与部署信任根证书取自独立项目 `E:\clb-pjs\downloadcenter`。分组 ID 是本机随机 UUID，仅用于本地计算和灰度决策；服务端只公开每个版本的灰度百分比，不获知客户端身份。Windows 更新助手不得在主程序仍运行时替换程序文件。首个支持更新的安装版本仍需由已有安装器升级，更新服务不能给尚未接入代码的历史二进制注入更新功能。腾讯云端点启用前必须配置可验证的 HTTPS 证书；私钥不得写入客户端或仓库。
