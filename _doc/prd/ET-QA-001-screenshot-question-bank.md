# ET-QA-001：截图知识库检索问答

- 需求编号：ET-QA-001
- 项目：Easy-Tools
- 来源：用户提出截图 OCR 后检索 Excel/Word 题库并回答
- 日期：2026-10-20

## 需求变更（2026-10-20）

界面中的“题库”统一改称“知识库”（保留兼容配置键 `question_banks`，避免用户升级后丢失数据）。明确告知用户内置 SmolLM2-360M 是轻量检索问答模型，仅适合根据已启用知识库返回原答案/证据，不适合开放域通用问答。截图、OCR、框选与提问可以继续组合已配置的本机模型或用户明确启用的云端模型；云端发送遵循已有逐项确认规则。所有新问答界面遵循 ET-PRIV-001，不得为处理内部截图或 OCR 暂时解除 Easy-Tools 窗口捕获排除。

## 需求

新增截图与 OCR 提问能力：用户在配置中心导入 Excel 题库，可添加多份题库并勾选启用，最多同时启用 3 份。截图框选后先进行 OCR，再从所有已启用题库检索候选问答。用户可直接返回题库原答案，或使用随安装包提供的 SmolLM2-360M-Instruct 本地量化模型；也可一键只读导入 CC Switch 当前 Claude / Codex 配置，选择其本机或云端模型，并用模型基于 OCR 和检索证据作答。支持面板手动提问与当前 OCR 文本提问。

导入格式仅支持 Excel `.xlsx`/`.xlsm`。每个工作表可配置表头行、题目列、正确答案列、独立答案内容列及 A～H 选项内容列；支持本地自动识别和 AI 辅助识别，AI 仅接收确认后的表头名称，识别结果由用户检查确认后保存。不再支持 Word 题库。

只有检索相关度达到阈值才展示题库匹配；模型不可用时回退题库原答案，无匹配且模型不可用时显示清楚的错误提示。CC Switch 配置只读，API 密钥不保存进 Easy-Tools 配置或日志。CC Switch 云端配置仅支持 HTTPS，并且必须经用户在导入流程中确认；请求正文包含 OCR 文字、问题和匹配题库参考内容。内置模型权重采用 GGUF Q4_K_M，文件约 271 MB；其运行时和权重随安装包提供，默认本地离线运行。小模型的中文生成能力有限，题库匹配时以原答案为准。

## 验收点

- [ ] 配置中心仅导入 `.xlsx`、`.xlsm`，读取常见问题/答案表头、两列工作表，并报告无效或空题库。
- [ ] 题库列表显示实际答案列；可按工作表手动配置题目列、答案列、答案内容列和选项内容列，保存映射后无需修改文件即可重新检索。
- [ ] 自动识别和 AI 辅助识别结果可检查/修改；AI 不发送题目、答案、完整文件或文件路径，关闭配置窗不导致后台线程崩溃。
- [ ] 截图答案显示在对应选区旁边，越界自动换边，不随等待期间的鼠标移动改变定位。
- [ ] 可添加/移除多份题库并勾选启用；任何保存/导入配置路径都必须保证最多启用 3 份。
- [ ] 截图 OCR 完成后，异步检索全部启用题库，按相关度选择候选并展示答案、题库来源和匹配问题；检索无匹配时不编造答案。
- [ ] 命中时能逐字展示题库原答案；启用本机模型后支持截图、当前 OCR 与手动问题的本地模型问答，失败时回退题库原答案。
- [ ] 可一键读取 CC Switch 当前启用的 Claude / Codex 配置，密钥从数据库即时读取且不写入 Easy-Tools；本机地址禁用代理并拒绝重定向。
- [ ] 用户明确确认云端导入后可调用 HTTPS 云端模型；未确认时拒绝发送 OCR/问题内容；拒绝云端重定向。
- [ ] 安装包内置 SmolLM2-360M-Instruct Q4_K_M GGUF 权重和 llama.cpp CPU 运行时，首次调用能启动本地推理；离线状态可完成回答。
- [ ] 隐私模式开启期间，截图覆盖层、设置页、面板和结果窗始终保持 Windows 捕获排除；主动截图只读取目标桌面，不临时解除应用窗口保护。
- [ ] 实际鼠标拖动、反向框选、Esc/右键取消、连续截图在隐私开关两种状态均不崩溃；绘图结束必须释放 QPainter。
- [ ] 截图等待启动按键松开后显示；GUI 控制器持有并释放会话，后台结果由 QObject GUI 槽函数接收。
- [ ] 背景 OCR 与主动截图共享识别引擎时串行执行推理，不并发修改同一后端状态。
- [ ] 打包后 EXE 可在隔离配置中执行真窗口回归：拖动绘制、100%/125%/150%/200% 缩放、正确答案列、取消、面板交互、真实 OCR；Windows GDI 验证隐私排除生效。
- [ ] OCR 异常、无文字、截图启动失败及题库检索失败均展示明确的应用内反馈，不依赖可能被隐私设置屏蔽的系统托盘提示。
- [ ] 截图覆盖层由 GUI 状态持有至截图/OCR/问答流程结束；选区结束后不得提前销毁信号发送对象，动作必须可靠触发覆盖层。
- [ ] 题库识别“题干/题目”及“正确答案/标准答案/参考答案/正确选项”等列；选择题答案为选项字母时可附上该选项文本；不得把“单选”等题型列当成答案。
- [ ] 支持实际题库表头“题目名称、题目类型、题目难度、答案1～答案5、正确答案”；正确答案列优先，选项字母映射至编号选项内容，多选保留全部正确项。
- [ ] 明确匹配且来源为正确答案列时，最终答案直接采用题库结果；本地/云端模型证据中标明答案来源列及原值，避免生成时替换正确答案。
- [ ] 识别到选择题选项列但缺少答案列时，导入/读取必须给出清晰错误，不静默退回第二列。
- [ ] 截图答案窗紧凑、非激活、不置顶；中键动作面板在答案窗出现期间仍可唤出和操作。
- [ ] 题库文件路径列自适应展示完整路径；路径可通过悬浮提示/右键操作查看和复制。
- [ ] 配置中心的勾选控件具有清楚的未选/已选状态，样式与浅色主题一致。
- [ ] 覆盖导入、解析、答案列选择、最多启用数、检索排序、回环限制、云端确认开关、重定向拦截、OCR 识别与模型失败回退。
- [ ] 生成新的程序目录包和安装器，验证实际 OCR 后端、内置模型推理及安装器载荷。
- [ ] 需求雷达验收点由用户手动确认，AI 不勾选完成。
- [ ] 答案弹窗复制/关闭及全局确认按钮、输入框、复选框在浅色界面和系统深色配色下清晰可读；普通/悬浮/按下/焦点/禁用状态明确，正文对比度至少 4.5:1；隐私与截图定位回归通过。
- [ ] 检索读取并可配置题型列，结合完整题干和询问意图区分简答/单选等题型；短题干重叠不直接满分，跨题型冲突不静默返回单选答案。
- [ ] 题库管理可配置仅显示答案内容；单选/多选通过答案内容列或选项映射返回原内容，不沿用题库 ABCD；缺少内容映射时明确提示，不猜选项。
- [ ] 用户可见界面、提示和文档统一使用“知识库”；旧配置键和值迁移兼容，不丢失已导入文件和列映射。
- [ ] 清楚提示内置 SmolLM2-360M 仅适合知识库检索回答；开放域及 OCR/截图提问由所选本机/云端模型处理，并明确数据是否离开本机。
