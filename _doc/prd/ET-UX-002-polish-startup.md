# ET-UX-002：界面层次优化与开机自启动

- 需求编号：ET-UX-002
- 标题：统一界面视觉层次、轻量交互及开机自启动
- 日期：2026-10-21
- 关联：ET-EVENT-001

## 强制约束

隐私模式是最高优先级红线，任何界面、动效、自启动修改均遵守 docs/privacy-design.md，禁止临时解除捕获排除或新增内容外发。

## 验收点
- [ ] 设置中心导航、头部工具区、内容区有清晰边界，统一配色、留白、焦点和选中反馈。
- [ ] “工具管理”作为主要功能始终显示在主导航；触发、面板、OCR、输入、隐私、性能和数据等配置页收拢到“综合配置”，配置页仍可直接访问且旧配置不迁移/丢失。
- [ ] 事件链编辑器区分流程列表和节点参数，支持调整分区宽度，原有编辑与试运行能力保留。
- [ ] 交互动效短暂且按需运行，无新增常驻渲染循环、模糊或阴影特效。
- [ ] 提供开机自启动开关，默认关闭，保存后设置当前用户启动项，关闭可移除，无需管理员权限；路径含空格可启动。
- [ ] 自启动写入失败明确提示，卸载清理属于本安装目录的启动项。
- [ ] 保留旧配置和数据，通过回归测试并构建新版本安装包、完成载荷自检。
- [ ] 用户手动确认需求雷达完成状态。
- [ ] 隐私模式下新旧窗口继续捕获排除，内部截图/OCR不解除保护，系统托盘通知继续屏蔽。
