# ET-UX-001：动作面板紧凑化与文本动作体验统一

- 需求编号：ET-UX-001
- 项目：Easy-Tools
- 来源：现有产品设计方案 `docs/设计方案.md` 与用户反馈
- 日期：2026-10-19

## 需求

优化动作面板的密度与视觉层次，确保面板在普通应用和软件专属场景中只显示公共动作以及当前软件命中规则的专属动作；改进逐字输入的中英文输入兼容和换行；统一动作库编辑与快速新增文本动作的表单体验。

## 验收点

- [ ] 动作面板默认每行显示更多动作格子，减少格子、分组标题与面板内边距的空白，同时保留名称可读性和完整名称提示。
- [ ] 面板只显示公共动作及当前前台软件匹配规则关联的专属动作；不匹配的软件专属动作不显示。
- [ ] 逐字输入按文本中英文自动切换输入状态，执行结束后恢复用户原输入状态；CRLF、LF、CR 换行都只产生一次换行，制表符行为明确且稳定。
- [ ] 动作库编辑动作与快速新增文本动作使用一致的通用字段表单外观和控件布局。
- [ ] 文本动作创建后仍同时正确生成片段和面板动作，保存即生效。
- [ ] 覆盖升级时清除当前载荷已不包含的旧运行库文件，避免旧 DLL 干扰 QtCore 加载。
- [ ] 动作弹窗采用紧凑的五列卡片网格、清晰的顶部工具栏和轻量提示区，动作名称不互相遮挡。
- [ ] 设置中心采用左侧导航与统一浅色内容区，表格、表单、按钮和底部保存栏视觉一致。
- [ ] 设置中心与动作弹窗统一为白底、浅灰分区和蓝色强调色，不保留深色侧栏或深色卡片。
- [ ] 动作弹窗默认每行 5 个更紧凑的卡片；每个分组使用相同网格宽度，末行不足 5 个时仍从左侧开始排列。
- [ ] 旧版默认面板配置升级后自动迁移到 5 列紧凑尺寸，用户自定义尺寸保留。
- [ ] 拟人逐字输入可按 Esc 中断，包括慢速字符等待；不继续执行后续输入链步骤，状态提示实际已输入数量。英文、数字和标点直接输入原字符，不触发中文组词；中文、emoji、CRLF/LF/CR 换行兼容，结束/取消后释放钩子并恢复输入状态。

## 2026-10-20 分类与分页补充

- [ ] 动作库增删改后立即重做分类筛选；删除分类最后一个动作仍停留该分类，不显示其他分类；上移下移只在筛选可见动作间进行。
- [ ] 面板支持配置大分类顺序，拖动或上移下移调整，文本输入默认优先；公共分类及命中的专属规则均按配置排序。
- [ ] 面板支持多 Tab 与连续分组两种模式；Tab 分类换行显示、网格左对齐，超出当前页使用分页按钮，全局搜索覆盖所有可见分类。
- [ ] Tab 模式只创建当前页动作控件，保持中键面板轻量响应，并保留原有隐私保护和上下文动作范围。

- [ ] 修复 Tab 切换、搜索及翻页时的搜索框与功能区错位或重叠；不同动作数量下头部与分类栏位置稳定，连续切换及不同缩放验证通过后重新打包。

- [ ] 动作库编辑普通文本动作与文本片段动作时，正文在独立多行文本框完整显示并可修改；片段类动作保存时同步更新关联文本片段，动作列表显示正文摘要。
