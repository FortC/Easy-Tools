# ET-AI-002：模型服务启停与本地/云端路由

- 需求编号：ET-AI-002
- 日期：2026-10-21
- 项目：Easy-Tools
- 关联：ET-PRIV-001、ET-QA-001

## 设计
- 本地服务启动/停止在后台执行，状态可查看。停止后终止本应用持有的 llama-server 进程，释放模型内存；持久化禁用状态，提问不自动重启。再次启动后可加载；只管理内置模型，不终止用户的 CC Switch/外部进程。
- 本地优先：本地→已授权云端；云端优先：已授权云端→本地。失败时最多尝试另一端一次。
- 混合：短问题优先本地；问题不少于800字符或知识库依据不少于3条时优先云端；本地关闭时走已授权云端；失败可回退。单次只走一个请求，不并行双发。
- 仅本地：禁止云端。仅云端：不调用或自动加载本地；选择并保存仅云端时释放本应用内置服务。
- 知识库确认答案仍优先直接返回，不消耗模型资源。
- 本地与云端分别导入 CC Switch 目标。云端仅允许 HTTPS；不复制API密钥至本配置；授权绑定应用与精确地址，地址变化必须重新导入确认。界面明确问题、OCR文字与知识库匹配内容发送到何处，可撤销授权。
- 默认仅本地；迁移已有显式授权的配置，不丢失旧设置。
- 隐私模式最高红线：所有窗口保留捕获排除，内部截图/OCR不临时解除，不静默外发，不记录敏感正文或凭据。

## 验收点
- [ ] 五种路由可配置且保存立即生效，各模式的调用顺序与范围遵循设计。
- [ ] 本地服务可反复启动/停止，停止中取消启动与推理，停止后不会因提问自动复活；不误杀外部模型服务。
- [ ] 启停与推理不阻塞界面；启动超时、失败和繁忙状态明确，状态显示不加载模型。
- [ ] 云端未授权或地址变化时禁止发送；仅本地绝不触发云端；云端失败不暴露请求内容或密钥。
- [ ] 混合仅单端请求，回退有界；知识库原答案路径不回退成模型改写。
- [ ] 原有配置迁移、隐私捕获排除、截图/OCR和通知回归通过。
- [ ] 测试及本机服务真实启停验证通过，更新版本并构建安装包，通过载荷自检。
- [ ] 完成状态由用户在需求雷达手动确认。
- [ ] 从配置文件导入新的云端授权时，先确认目标地址与内容范围；取消则不导入、不授予权限。
- [ ] 提供“极速版”（不打包模型权重）和“完整版”（内置模型权重）两种可独立构建的安装包；极速版模型页提供用户主动触发的下载、进度/取消、SHA-256 校验和本机加载，文件保存到用户可写数据目录，HTTPS 来源固定且不上传任何用户内容。
- [ ] 极速版缺模型、下载失败或校验失败时显示清晰状态并保持其它功能可用；下载/模型设置页继续受 CapturePrivacyFilter 保护，隐私模式通知行为不变。
