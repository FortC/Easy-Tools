# ET-EVENT-001：事件链编排器

- 需求编号：ET-EVENT-001
- 项目：Easy-Tools
- 来源：用户提出将目前不可用的事件操作升级为可组合的可视化链式编排能力
- 日期：2026-10-20

## 需求

提供面向普通用户的事件链构建器，用有序节点表达触发、输入采集、变量转换、条件分支、内置动作、Python 脚本和结果输出。典型流程可从当前选中文本/剪贴板/OCR 获取输入，调用内置处理器或脚本，最后复制、输入或显示结果。支持节点重排、变量创建/更新、输入输出映射、试运行和逐步错误提示。未来扩展 MCP、邮件、HTTP 等外部工具时，必须采用明确的连接配置与用户授权，不得静默上传内容。所有节点 UI 和运行结果遵循 ET-PRIV-001；云端调用需说明发送的数据。隐私实现要求详见 [docs/privacy-design.md](../../docs/privacy-design.md)。

## 验收点

- [ ] 节点类型和参数使用易读名称、表单和简短说明呈现，不要求普通用户编写 JSON。
- [ ] 支持有序节点、拖动排序/上下移动、添加删除复制，并可查看每步输入、输出和错误。
- [ ] 支持选中文本/剪贴板/OCR 输入、变量创建/修改、文本模板/处理器、条件分支、等待、调用已有动作和结果输出。
- [ ] 支持用户显式配置的 HTTP 外部工具，具备超时/响应错误处理、敏感信息遮罩及请求内容发送前提示。
- [ ] 支持试运行和取消；试运行不产生输入/剪贴板等未确认副作用。
- [ ] 支持 Python 脚本节点，在独立子进程运行，输入为当前步骤文本和变量 JSON，输出作为后续步骤文本；支持超时与取消，不记录脚本正文或输入内容。
- [ ] Python 节点默认关闭；用户必须主动勾选信任确认，界面清楚说明脚本以当前 Windows 账户权限运行，可读取文件、访问网络和自行截屏（可能绕过应用窗口捕获排除）；不得宣称该隔离等同安全沙箱。
- [ ] 未授权/未信任的 Python 节点在运行时明确失败；试运行也遵循同一信任提示和超时限制。
- [ ] 未授权时不调用外部工具、不发送数据；MCP/邮件仅在具备明确连接配置和授权流程后开放。
- [ ] 新增窗口默认应用 ET-PRIV-001 捕获排除；内部截图与 OCR 不解除隐私保护。
- [ ] 旧事件链数据可读取；无效旧步骤仍显示错误并允许用户修复，不破坏已保存配置。
- [ ] 低配设备上编辑/试运行不阻塞主界面，循环有上限、网络请求有超时。
- [ ] 需求雷达验收点由用户手动确认，AI 不勾选完成。
