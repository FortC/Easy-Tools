# ET-PERF-001：卡顿排查与运行稳定性优化

- 需求编号：ET-PERF-001
- 项目：Easy-Tools
- 来源：用户反馈“偶发无响应”，追求好用、极速、稳定
- 日期：2026-10-20

## 需求

排查 Easy-Tools 偶发无响应的根因，修复会阻塞界面或造成线程/资源堆积的缺陷，优化高频路径并重新打包。优化以保持现有功能为前提，避免破坏输入、面板、OCR、截图、配置保存和隐私保护。

## 验收点

- [ ] 通过代码、日志和可控测试定位导致无响应的高风险路径，并修复确认的问题。
- [ ] GUI 主线程不执行可避免的阻塞 I/O、长耗时识别、等待或重复全量工作。
- [ ] 后台任务有明确超时/停止/重复触发控制，异常不会让服务状态失控。
- [ ] 面板反复打开/搜索/关闭、配置保存重载等高频路径保持响应，不持续累积定时器、线程或事件。
- [ ] 回归测试覆盖修复点及关键核心功能；全套自动测试通过。
- [ ] 生成新的版本目录包和安装器，并通过载荷完整性及 QtCore 加载检查。
- [ ] 需求及验收点记录在需求雷达收件箱；PRD 与记录不由 AI 标记为完成。
- [ ] 低配优化：题库导入、表头读取/配置确认、配置保存移至有上限的后台任务；GUI 列表刷新不重新读 Excel。
- [ ] OCR 与内置模型限制 CPU 并发并保留界面资源；模型启动/停止不在 GUI 等待长锁；重复提问/截图任务不无限积压，显示处理中状态。
- [ ] 检索预计算题干规范化/词项，配置或文件变化后更新索引，移除题库后释放缓存。
- [ ] 配置中心从托盘/动作按钮打开统一经 GUI 队列槽，窗口最小化/隐藏/屏幕变化后可恢复，已有模态窗口优先置前；托盘显示面板支持单击/双击，重载配置不阻塞 GUI。
- [ ] 启动时托盘通知槽必须先定义后连接，回调再次检查隐私通知开关；最终 EXE 的正常启动路径能进入托盘就绪阶段，不出现未定义回调异常。
- [ ] 卸载采用独立无控制台程序，启动器只转交一次；不使用递归 CMD/PowerShell，不保留后台重启循环，清理重试有上限。
- [ ] 安装器识别注册表记录和默认目录中的旧版本，默认原目录覆盖升级；仅结束该目录下的程序/模型进程，保留用户配置和非程序文件，更新卸载入口并清理已移除的旧文件。
- [ ] 卸载按安装文件清单删除并校验绝对路径边界，保留清单外文件及 APPDATA 用户配置；卸载注册表和快捷方式只清理归属当前安装目录的项。
- [ ] 同时发现多处旧目录时可选择；旧注册记录指向临时目录时优先常规安装目录，检查在后台执行。
