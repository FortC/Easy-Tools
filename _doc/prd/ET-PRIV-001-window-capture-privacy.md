# ET-PRIV-001：应用通知控制与窗口捕获隐私

- 需求编号：ET-PRIV-001
- 项目：Easy-Tools
- 来源：用户反馈与隐私设置需求
- 日期：2026-10-20

## 需求

提供关闭右下角应用通知的设置，并为 Easy-Tools 自身窗口提供系统截图/录屏捕获排除选项。隐私选项应覆盖动作面板、设置窗口及应用创建的顶层对话框，并在设置修改后立即生效。

隐私保护是应用的持续设计约束：新增的动作分类、事件链节点、知识库/AI 提问、截图和设置 UI 都必须沿用窗口捕获过滤机制；不得为内部截图/OCR临时取消窗口排除，也不得在未明确告知/授权时把 OCR、选区、剪贴板或知识库文本发送到云端。Windows 捕获排除只覆盖受支持的系统捕获路径，不对直接进程读取、辅助功能或物理拍摄作保证。

## 验收点

- [ ] 设置中心可单独关闭全部 Easy-Tools 右下角通知；关闭后成功和失败通知均不显示，日志记录不受影响。
- [ ] 设置中心提供窗口捕获隐私开关，默认启用，设置保存后立即应用/移除 Windows 窗口捕获排除属性。
- [ ] 动作面板、设置窗口及应用创建的顶层对话框在显示时都应用隐私属性，运行期间新打开的窗口也能应用。
- [ ] 通过受支持系统捕获 API 获取画面后再进行 OCR/Canvas 处理时，Easy-Tools 窗口像素不出现在捕获画面中。
- [ ] 隐私设置说明仅保证在 Windows DWM 和受支持的系统捕获 API 范围内工作，不承诺阻止摄像、所有第三方采集或绕过式录制。
- [ ] 明确说明无法通用阻止直接读取进程/窗口内部数据或辅助功能信息的 OCR 工具。
- [ ] 无法应用系统属性时记录可诊断日志，不导致主界面或动作运行崩溃。
- [ ] 旧配置升级后补齐隐私配置，并且可以正常保存、重载和导入。
- [ ] 自动化验证覆盖通知开关、配置迁移、窗口显示时应用捕获属性及关闭隐私后的恢复。
- [ ] 事件链、AI、知识库及后续新增的所有顶层窗口默认继承隐私过滤；内部捕获/OCR流程不改变该状态；未经用户明确选择云端服务不上传上下文内容。
